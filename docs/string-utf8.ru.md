# Явное преобразование UTF-8

`"Привет".toUtf8()` возвращает новый изменяемый ByteArray с байтами `#D09FD180D0B8D0B2D0B5D182`. Метод не принимает аргументов и требует строковый receiver. Каждый вызов создаёт независимый буфер.

`String.fromUtf8(bytes)` принимает ровно один ByteArray (включая потомка с собственным байтовым payload) и возвращает строковый снимок. Receiver — прототип String. Пустой ввод даёт пустую строку; встроенный NUL, BOM (U+FEFF) и символы вне BMP сохраняются. BOM не добавляется и не удаляется. Изменение байтов после декодирования не влияет на строку.

Неверный UTF-8, типы или число аргументов дают `INVALID_ARGUMENT`. Неверный receiver или отдельный вызов извлечённого метода дают `INVALID_OPERATION`. Отвергаются избыточные кодировки, одиночные continuation bytes, суррогаты, обрывы последовательностей и значения выше U+10FFFF. Подстановок и неявного преобразования нет.

`str(bytes)` по-прежнему возвращает hex-литерал, а не текст. Методы используют общий кодек Unicode с явной длиной, независимо от locale и ширины wchar_t. Временный буфер encoder освобождается после копирования; декодированная строка передаётся во владение String. Наблюдение ByteArray сохраняет обработку модульных ошибок/доступа. Консервативные эффекты встроенных функций не позволяют кэшировать изменяемые байты; native scalar ABI не меняется. Overflow/OOM следует фатальной политике общей библиотеки.
