## Описание сборки

Для сборки модуля потребуется создать JSON-файл с расширением `.gmod`.
Например, `geometry.gmod`:

```json
{
  "formatVersion": 1,
  "name": "geometry",
  "version": "1.2.0",
  "main": "src/main.goat",
  "dependencies": {
    "math": "2.0.0"
  },
  "native": {
    "mode": "auto",
    "target": "host"
  }
}
```

Поля `formatVersion`, `name`, `version`, `main` обязательны.
`formatVersion` должен быть целым JSON-числом `1`, не `1.0` и не `1e0`.
`name` задаёт имя модуля, `version` — его точную строковую версию.
`main` — путь к входному файлу `.goat`, относительно расположения `.gmod`.

Необязательное `dependencies` — объект, в котором ключи являются именами
модулей, а значения — точными строковыми версиями. Необязательное `native`
задаёт режим `off`, `auto` (по умолчанию) или `required` и целевую
платформу `target` (по умолчанию `host`). Другие настройки компилятора
передаются командной строкой или окружением, а не машинными путями в `.gmod`.

Неизвестные поля и повторяющиеся ключи JSON запрещены, в том числе ключи,
совпадающие после декодирования `\\u`-последовательностей. Файл должен
содержать корректный UTF-8 без BOM. Строки Unicode не нормализуются.
Числовые поля разбираются точно, без промежуточного округления в `double`.

## Имена и версии

К именам модулей, строкам версий, ключам и значениям `dependencies`
применяются одинаковые правила символов:

- Только строчные латинские буквы `a-z`, цифры `0-9`, точка `.`,
  подчёркивание `_` и дефис `-`. Никаких пробелов, Unicode и `NUL`.
- Первый символ — буква или цифра; пустые строки запрещены.
- Последняя точка запрещена, но последовательные точки внутри строки
  и завершающие `-` и `_` разрешены.
- Зарезервированные имена устройств Windows запрещены на всех платформах:
  `con`, `prn`, `aux`, `nul`, `com0`–`com9`, `lpt0`–`lpt9`,
  в том числе с расширением, например `con.txt`.
- Максимальная длина имени — **255 байт**, версии — **250 байт**;
  символы ASCII занимают по одному байту.
- Регистр не исправляется автоматически; версии — непрозрачные строки,
  без SemVer, числового разбора и сравнения по старшинству.
  `1.02.0` и `1.2.0` различаются.

Эти ограничения нужны для одинакового размещения модулей на Linux и Windows:
`geometry/1.2.0.gbin`. Проверка не зависит от локали.

## Подключение зависимостей

Согласованный синтаксис исходников:

```goat
const math = import "math";          // Версия из dependencies.
const oldMath = import "math@1.2.0"; // Явно указанная версия.
```

Если `@` отсутствует, версия должна быть указана в `.gmod`.
Если `@` есть, имя и версия по обе стороны обязательны. Нельзя указывать
несколько `@`. Явная версия действует только для одного `import`.

Общий C API проверки имён и разбора спецификаций импорта находится в
`include/goat/module_identity.h`. Он принимает длину, не требует завершающего
нулевого символа и не выделяет память. Существующий `string_view_t` не изменяется.
Для компилятора с `wchar_t` предусмотрен отдельный разбор широких строк.
