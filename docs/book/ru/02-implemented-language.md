## 2.1. Сначала — поведение программы

Чтобы понять интерпретатор, нужно сначала договориться о том, что он исполняет. Запись `6 / 4` выглядит знакомо, но результат зависит от правил языка: это может быть целое число, вещественное число или ошибка. Именно такие правила составляют семантику языка (значение его конструкций и операций).

Goat использует знакомые обозначения: `var`, `const`, `if`, `func`, `return`, фигурные скобки и вызовы через круглые скобки. Сходство записи не означает полного совпадения с C или JavaScript. В этой главе рассматривается реализованное поведение, необходимое для дальнейшего чтения книги. Полные справочные таблицы предусмотрены в приложениях.

Примеры сохранены в [общем каталоге](../examples/). После сборки интерпретатора их можно запускать из корня репозитория. Например, на Linux:

```sh
./goat --native off docs/book/examples/02-values.goat
```

В Windows PowerShell:

```powershell
.\goat.exe --native off .\docs\book\examples\02-values.goat
```

Здесь нативное исполнение отключено: пока нас интересуют правила языка, которые реализует VM (программа, выполняющая инструкции байткода).

## 2.2. Значения и имена

У значения есть тип, определяющий допустимые операции. Переменная хранит значение, но её объявление не задаёт неизменный тип. В примере ниже `value` сначала содержит целое число, затем — вещественное.

[Пример значений и условий](../examples/02-values.goat):

```goat
var value = 6;
value = value / 4;
println(value);
const limit = 10;
if (value < limit && value != 0) {
    println("within limit");
}
println(9223372036854775807 + 1);
println(!!"");
println(!!{});
```

Результат:

```text
1.5
within limit
-9223372036854775808
false
false
```

`var` объявляет переменную, которой можно присвоить новое значение. `const` объявляет константу: повторное присваивание этому имени запрещено. Это ограничение относится к привязке имени к значению, а не является общим обещанием неизменности всего связанного с ним состояния. Например, константа может хранить функцию, меняющую захваченную переменную.

Основные значения, встречающиеся в программах:

| Значение | Пример | Назначение |
|---|---|---|
| Целое число | `42`, `-7` | Знаковые целые с 64-битным представлением |
| Вещественное число | `1.5`, `1.0` | Числа в представлении C `double`, с конечной точностью |
| Строка | `"text"`, `"\n"` | Текст; `\n` обозначает перевод строки |
| Логическое значение | `true`, `false` | Результат сравнения или логической операции |
| Отсутствующее значение | `null` | В частности, значение отсутствующего аргумента |
| Функция | `func(x) { return x; }` | Вызываемое значение, которое можно передать или вернуть |
| Пользовательский объект | `{ var x = 2; }` | Набор свойств, полученный при выполнении блока |

Область видимости (участок программы, где доступно имя) позволяет объявлять локальные переменные. Вложенное объявление может затенить внешнее: одинаковое написание имени ещё не означает одну и ту же переменную.

В этой реализации возможно и неявное объявление: при связывании неизвестного имени анализатор добавляет для него объявление переменной. Поэтому опечатка в имени не обязательно становится ошибкой компиляции. В примерах книги мы используем явные объявления, чтобы было видно, где возникает каждая переменная. Этот механизм реализован в [связывании имён](https://github.com/kniazkov/g0at/blob/cf51b8cb27a102d15260c7822ce503404462b0fd/src/analysis/analysis.c).

## 2.3. Числа: знакомые операции, конкретные правила

Для целых чисел поддерживаются сложение, вычитание и умножение с переполнением по модулю \(2^{64}\) (сохраняются младшие 64 бита результата). Поэтому прибавление единицы к максимальному знаковому целому в примере даёт минимальное отрицательное. Унарный минус и увеличение или уменьшение на единицу также учитывают это правило.

Деление следует правилу наименьшего удивления: от записи `6 / 4` естественно ожидать `1.5`, без потери дробной части. Это ориентир при выборе поведения языка, а не универсальное ожидание каждого программиста: привычка к целочисленному делению в C может подсказывать другой ответ. Поэтому правило задаётся явно. `6 / 3` даёт целое `2`, а `6 / 4` — вещественное `1.5`. Если целый результат не помещается в знаковые 64 бита, как при делении минимального целого на `-1`, возвращается вещественное число. Деление на ноль вызывает исключение. Оператор `%` вычисляет остаток для целых аргументов; знак ненулевого остатка совпадает со знаком делимого. `**` — возведение в степень с вещественным результатом.

В смешанной арифметике, например `2 + 0.5`, целое преобразуется в `double`. Большое целое при таком преобразовании может округлиться: вещественное представление не хранит все 64-битные целые точно. При этом смешанные сравнения реализованы отдельно и не сводятся к безусловному преобразованию обоих чисел в `double`.

Есть также побитовые операции (работа с отдельными битами целого числа): `~`, `&`, `|`, `^`, `<<`, `>>`. Они отличаются от логических `!`, `!!`, `&&`, `||`. Сравнения записываются как `<`, `<=`, `>`, `>=`, `==`, `!=`.

Эти правила можно проверить в [целых числах](https://github.com/kniazkov/g0at/blob/cf51b8cb27a102d15260c7822ce503404462b0fd/src/model/integer.c), [вещественных числах](https://github.com/kniazkov/g0at/blob/cf51b8cb27a102d15260c7822ce503404462b0fd/src/model/real.c) и [общих числовых операциях](https://github.com/kniazkov/g0at/blob/cf51b8cb27a102d15260c7822ce503404462b0fd/src/model/number.c). Для будущего генератора C они обязательны: перенос привычного оператора C без проверки его поведения может изменить результат Goat-программы.

## 2.4. Условия и порядок вычисления

`if` выбирает ветвь по истинности значения (его трактовке как «истина» или «ложь»). Ложными считаются `null`, `false`, числовой ноль, пустая строка и пользовательский объект без свойств. Ненулевые числа, непустые строки, функции и объекты со свойствами истинны. Для вещественных чисел проверяется неравенство нулю; NaN (специальное значение «не число») тоже считается истинным.

`!` отрицает истинность, а `!!` превращает её в `true` или `false`. `&&` и `||` возвращают логические значения и используют короткое замыкание (не вычисляют правую часть, когда результат уже определён). Поэтому в выражении `false && f()` вызова `f` не будет. Проверки этих правил находятся в [тесте истинности](https://github.com/kniazkov/g0at/blob/cf51b8cb27a102d15260c7822ce503404462b0fd/test/functional/logic_truth/program.goat) и [таблицах логических операций](https://github.com/kniazkov/g0at/blob/cf51b8cb27a102d15260c7822ce503404462b0fd/test/functional/logic_truth_tables/program.goat).

Приоритет определяет группировку выражения: `2 + 3 * 4` означает `2 + (3 * 4)`. Порядок вычисления отвечает на другой вопрос: какое действие произойдёт раньше. В обычных бинарных операциях сначала вычисляется левый операнд, затем правый. У вызова функции порядок иной: аргументы вычисляются справа налево, затем вычисляется само выражение, обозначающее вызываемую функцию.

[Пример порядка аргументов](../examples/02-order.goat):

```goat
var x = 0;
const show = func(a, b) {
    print(a); print("|"); println(b);
};
show(x++, x++);
println(x);
```

Он выводит:

```text
1|0
2
```

Постфиксное `x++` возвращает прежнее значение и увеличивает переменную. Сначала правый аргумент получает `0`, затем левый — `1`. Параметры при этом не переставляются: `a` получает левый аргумент, `b` — правый. Префиксное `++x` возвращает уже увеличенное значение. Аналогично различаются `x--` и `--x`.

Порядок вызова явно задан в [генерации байткода и анализе вызова](https://github.com/kniazkov/g0at/blob/cf51b8cb27a102d15260c7822ce503404462b0fd/src/graph/function_call.c). Его необходимо сохранять при оптимизации, иначе выражения с изменением переменных начнут давать другой результат.

### Повторение с помощью for

Цикл `for` повторяет оператор, пока его условие истинно. Порядок действий: один раз `initial`, затем `condition`, `statement`, `step` и новая проверка условия:

```goat
for (initial; condition; step) statement
```

Инициализация может быть выражением или объявлением `var`/`const`. Условие и шаг — выражения. Любую часть можно оставить пустой; пропущенное условие означает `true`. Пустое тело записывается как `;`. Фигурные скобки объединяют несколько операторов; одному оператору они не нужны. Циклы и `if/else` можно вкладывать друг в друга; `else` относится к ближайшему незавершённому `if`.

[Пример](../examples/02-for.goat):

```goat
var sum = 0;
for (var i = 0; i < 5; i++) sum = sum + i;
println(sum);
for (var row = 0; row < 2; row++)
    for (var column = 0; column < 2; column++)
        println(row * 10 + column);
```

Он выводит `10`, `0`, `1`, `10` и `11` на отдельных строках. Переменная, объявленная в заголовке, принадлежит циклу и недоступна после него. Тело получает свежую область видимости на каждой итерации, в том числе без фигурных скобок. Замыкание, захватывающее переменную заголовка, удерживает общий счётчик; замыкание, захватывающее локальную переменную тела, удерживает привязку конкретной итерации.

`return` сразу покидает содержащую функцию, а исключение передаёт управление обработчику. Оставшийся шаг этой итерации в обоих случаях не выполняется.

> [!CAUTION]
> `while`, `do/while`, `break` и `continue` не реализованы. Общего оператора запятой нет: шаг `i++, j++` не поддерживается. Несколько объявлений вида `var i = 0, j = 3` в инициализации допустимы.

## 2.5. Функция сохраняет окружение

`func` создаёт значение-функцию. При вызове аргументы связываются с параметрами; `return` завершает вызов и передаёт результат вызывающему коду. Если функция заканчивается без возвращённого значения, результатом служит `null`.

У пользовательских функций отсутствующие аргументы заменяются на `null`. Лишние аргументы вычисляются, включая их побочные эффекты, но не получают соответствующих параметров. Встроенные функции могут предъявлять свои требования к числу аргументов.

Функция может использовать переменную из внешней области. Такое сочетание функции с сохранённым окружением называется замыканием. Оно позволяет продолжать работу с данными после завершения вызова, который их создал.

[Пример счётчика](../examples/02-functions.goat):

```goat
const make_counter = func(start) {
    var value = start;
    return func() {
        value = value + 1;
        return value;
    };
};
const next = make_counter(10);
println(next());
println(next());
const first = func(a, b) { return a; };
println(first());
```

Результат:

```text
11
12
null
```

Вызов `make_counter(10)` уже завершился, а возвращённая функция всё ещё обращается к `value`. Она сохраняет доступ к переменной, а не только к числу `10`: второй вызов видит изменение первого. Константа `next` хранит эту функцию и не переназначается.

Функции могут вызывать себя рекурсивно (повторно входить в собственное тело с новыми аргументами). Пример Фибоначчи из первой главы использует именно это. Создание окружения, передача аргументов и удержание захваченных данных реализованы в [объекте функции](https://github.com/kniazkov/g0at/blob/cf51b8cb27a102d15260c7822ce503404462b0fd/src/model/function.c).

## 2.6. Блок как объект и выход через исключение

Фигурные скобки в Goat могут образовывать выражение. При нормальном завершении такого блока его локальные данные становятся объектом-результатом. Это позволяет, например, вернуть несколько именованных значений из функции. Вложенный блок может обращаться и к внешним переменным; явное `var` помогает отличить создание локального свойства от изменения внешнего имени.

Исключение (значение, передаваемое обработчику вместо обычного продолжения исполнения) задаёт другой путь выхода. `throw` может передать любое Goat-значение, а `catch` связывает его с указанным именем. Исключения операций также проходят через этот механизм.

[Пример объектов и исключений](../examples/02-objects-exceptions.goat):

```goat
const point = {
    var x = 2;
    var y = 3;
};
println(point);
try {
    println(1 / 0);
} catch (error) {
    print("caught: "); println(error);
}
try {
    throw "stop";
} catch (error) {
    println(error);
}
```

Результат:

```text
{"x":2,"y":3}
caught: DIVISION_BY_ZERO
stop
```

При делении на ноль вызов `println(1 / 0)` не доходит до печати результата: управление передаётся ближайшему подходящему обработчику. После завершения обработчика программа продолжает работу. Без обработчика исключение выводится как необработанная ошибка, и запуск завершается с ошибкой.

`DIVISION_BY_ZERO` в этом примере — строковое значение ошибки, а не экземпляр обязательного класса исключений. Такие стандартные значения собраны в объекте `Exceptions`. Создание результата блока описано в [списке инструкций](https://github.com/kniazkov/g0at/blob/cf51b8cb27a102d15260c7822ce503404462b0fd/src/graph/statement_list.c), а выполнение обработчиков — в [VM](https://github.com/kniazkov/g0at/blob/cf51b8cb27a102d15260c7822ce503404462b0fd/src/vm/vm.c). Проверяющие примеры: [возврат объекта](https://github.com/kniazkov/g0at/blob/cf51b8cb27a102d15260c7822ce503404462b0fd/test/functional/return_object/program.goat) и [необработанное исключение](https://github.com/kniazkov/g0at/blob/cf51b8cb27a102d15260c7822ce503404462b0fd/test/functional/throw_uncaught/program.goat).

## 2.7. Что предоставляет окружение

Перед пользовательским кодом доступны встроенные функции (функции, реализация которых поставляется с интерпретатором). `print` выводит значение без автоматического перевода строки, а `println` добавляет после него `\n`. Обе функции возвращают `null` и требуют хотя бы один аргумент; пустую строку можно вывести как `println("")`. Лишние аргументы вычисляются, но не печатаются. `input` читает ввод, `int` выполняет преобразование к целому. Числовой набор включает, например, `abs`, `sqrt`, `sin`, `cos`, `min`, `max`, `floor`, `ceil` и `round`. Также доступны `pi` и `Exceptions`.

Встроенные функции собраны в [едином реестре](https://github.com/kniazkov/g0at/blob/cf51b8cb27a102d15260c7822ce503404462b0fd/src/builtins/registry.c). Этот реестр связывает имя с реализацией и сведениями для анализа. Само написание имени не гарантирует встроенное поведение: локальное объявление `print` может затенить встроенную функцию.

Для чтения следующих глав важно разделять три вопроса. Можно ли записать конструкцию в исходнике? Может ли VM её выполнить? Может ли анализатор доказать свойства, достаточные для генерации C?

> [!CAUTION]
> Например, счётчик с изменяемой захваченной переменной работает в VM, но не входит в поддерживаемое нативное числовое подмножество. Наличие объекта в языке тоже не означает наличия нативного представления произвольных объектов.

Далее мы проследим эти границы на одной программе.
