## Г.1. Общие правила вызова

В [registry.c](https://github.com/kniazkov/g0at/blob/5b98271e26cb17bdc5589aaf827316016ba2e00a/src/builtins/registry.c) определён реестр встроенных функций. Таблицы ниже описывают числовые и строковые семейства; операции процесса и потоков перечислены отдельно ниже. `pi` и `Exceptions` — значения корневого окружения, не функции. Имена `Object`, `String`, `Number`, `Integer`, `Real`, `Character`, `Boolean`, `Function` и `Null` тоже не функции: это прототипы типов, открытые корневым контекстом. Имя можно затенить своим объявлением; обработчик выбирается по объекту встроенной функции, а не по одному написанию имени.

Минимум аргументов проверяется общей обёрткой: недостаток даёт строковое исключение `INVALID_ARGUMENT`. У числовых функций и функций вывода фиксированной арности лишние аргументы предварительно вычисляются и затем игнорируются, кроме второго аргумента `int`, который задаёт резервное значение. Вариативные `spawn` и `format` используют дополнительные аргументы. Даже `println()` без аргумента вызывает ошибку; пустую строку печатают через `println("")`.

<a id="section-d-2"></a>

## Г.2. Вывод, ввод и специальные числовые функции

| Функция | Минимум | Поведение |
| --- | --- | --- |
| `print(x)` | 1 | Печатает только x, без разделителя и перевода строки; возвращает null. |
| `println(x)` | 1 | То же, затем один перевод строки; возвращает null. |
| `input()` | 0 | Читает строку без завершающего перевода строки; EOF до данных даёт пустую строку. Ошибка чтения — INVALID_OPERATION. |
| `int(x, fallback)` | 1 | Преобразует в целое; при неудаче возвращает второй аргумент без преобразования либо 0. |
| `abs(x)` | 1 | Модуль числа; сохраняет целый или вещественный тип. |
| `sign(x)` | 1 | Целое −1, 0 или 1; для NaN возвращает 0. |
| `instanceOf(proto)` | 1 | Метод `value.instanceOf(proto)`; `true`, если proto в цепочке прототипов value. |

Функция-форма `instanceOf(value, proto)` требует двух аргументов; недостаток даёт `INVALID_ARGUMENT`. Проверка идёт по тождеству и топологии предков приёмника, без преобразования типов. Метод определён на корневом объекте и доступен у любого значения, включая литералы примитивов: `null.instanceOf(Object)`, `(13).instanceOf(Number)`, `(3.14).instanceOf(Real)`. Целое перед точкой берут в скобки: запись `13.instanceOf(...)` читается как вещественный литерал.

`int` принимает целое без изменения; `false`/`true` превращает в 0/1. Конечное вещественное должно лежать в диапазоне [-2^63, 2^63); дробная часть отбрасывается к нулю. Строка должна целиком содержать знаковое десятичное число с допустимыми ASCII-пробелами по краям, без переполнения. `NaN`, бесконечности, неподходящие строки и другие объекты дают резервный результат, а не исключение преобразования.

`abs(INT64_MIN)` насыщается до `INT64_MAX`. `abs` и `sign` с нечисловым аргументом дают `INVALID_ARGUMENT`. Вывод использует текстовое представление объекта; логическая истина и преобразование в число — разные операции.

## Г.3. Математические функции

Все следующие функции принимают целые и вещественные, преобразуют операнды в `double` и возвращают вещественный результат, включая `floor`, `round`, `min` и `max`. Тригонометрические аргументы и результаты обратных функций выражены в радианах.

| Функция | Минимум | Назначение |
| --- | --- | --- |
| `acos(x)` | 1 | Арккосинус |
| `asin(x)` | 1 | Арксинус |
| `cbrt(x)` | 1 | Кубический корень |
| `ceil(x)` | 1 | Округление вверх |
| `cos(x)` | 1 | Косинус |
| `cosh(x)` | 1 | Гиперболический косинус |
| `exp(x)` | 1 | Экспонента e^x |
| `exp2(x)` | 1 | Степень 2^x |
| `expm1(x)` | 1 | e^x − 1 |
| `floor(x)` | 1 | Округление вниз |
| `log(x)` | 1 | Натуральный логарифм |
| `log10(x)` | 1 | Десятичный логарифм |
| `log1p(x)` | 1 | Натуральный логарифм 1 + x |
| `log2(x)` | 1 | Двоичный логарифм |
| `round(x)` | 1 | Округление к ближайшему, половины от нуля |
| `sin(x)` | 1 | Синус |
| `sinh(x)` | 1 | Гиперболический синус |
| `sqrt(x)` | 1 | Квадратный корень |
| `tan(x)` | 1 | Тангенс |
| `tanh(x)` | 1 | Гиперболический тангенс |
| `trunc(x)` | 1 | Отбрасывание дробной части к нулю |
| `atan(x)` / `atan(y, x)` | 1 | Арктангенс x; угол по y и x, C atan2(y, x) |
| `fmod(x, y)` | 2 | Вещественный остаток x/y |
| `hypot(x, y)` | 2 | Длина по двум компонентам |
| `max(x, y)` | 2 | Максимум пары, C fmax |
| `min(x, y)` | 2 | Минимум пары, C fmin |
| `pow(x, y)` | 2 | Степень x^y |

Нечисловой операнд даёт `INVALID_ARGUMENT`. Ошибки области определения и переполнение самой C-математики не преобразуются автоматически в исключения Goat: возможны `NaN` и бесконечности. `min`/`max` используют `fmin`/`fmax`, включая их обработку NaN; они не обходят произвольный список аргументов. `fmod` и целочисленный `%` — разные операции.

## Г.4. Абстрактные результаты и эффекты

Обработчики анализа не выполняют ввод-вывод. `print`/`println` дают домен `null` и эффект `output`; `input` даёт `string` и эффект `input`. Числовые функции ниже имеют `effects=none`, что не исключает ошибку аргумента. `instanceOf` даёт домен логических значений при наличии аргументов и `BOTTOM` при их отсутствии.

Общие математические обработчики вычисляют константу для известных чисел, иначе дают `real` при числовом или ещё неизвестном типе; определённо неподходящий тип даёт `BOTTOM`. `abs` сохраняет известную числовую категорию, но не вычисляет точный образ произвольного целого диапазона. `sign` может вычислить константу или диапазон внутри [-1..1]. `int` сохраняет целые сведения; для общего boolean даёт [0..1], а при неизвестной успешности объединяет `integer` с резервным результатом.

Эти сведения описывают обычный результат, а не полный граф исключений. Встроенная C-реализация также не означает, что вызов разрешён внутри генерируемой C-специализации: это отдельный контракт главы 20.

## Г.5. Строковые методы и функция str

Строковый прототип [string.c](https://github.com/kniazkov/g0at/blob/5b98271e26cb17bdc5589aaf827316016ba2e00a/src/model/string.c) открывает методы, доступные у строки в форме `"текст".имя(аргументы)`. Каждый метод также доступен как функция с префиксом строки первым аргументом, например `charAt("abc", 1)` равнозначен `"abc".charAt(1)`. Неподходящий приёмник или аргумент даёт `INVALID_ARGUMENT`.

| Метод | Минимум | Поведение |
| --- | --- | --- |
| `charAt(index)` | 1 | Символ строки по индексу от 0; выход за границы — INVALID_ARGUMENT. |
| `substring(begin, end)` | 1 | Подстрока от begin до end (не включая); end необязателен и по умолчанию равен длине. begin<0, end<begin или end>длина — INVALID_ARGUMENT. |
| `contains(str)` | 1 | true, если строка содержит подстроку; пустая подстрока всегда содержится. |
| `indexOf(str)` | 1 | Индекс первого вхождения подстроки или −1; пустая подстрока даёт 0. Аргумент может быть строкой или символом. |
| `lastIndexOf(str)` | 1 | Индекс последнего вхождения подстроки или −1; пустая подстрока даёт длину. Аргумент может быть строкой или символом. |
| `startsWith(str)` | 1 | true, если строка начинается с префикса; пустой префикс — true. Аргумент может быть строкой или символом. |
| `endsWith(str)` | 1 | true, если строка заканчивается суффиксом; пустой суффикс — true. Аргумент может быть строкой или символом. |
| `isEmpty()` | 0 | true для строки нулевой длины. |
| `isBlank()` | 0 | true, если строка пуста или состоит только из пробельных символов. |
| `toUpperCase()` | 0 | Строка в верхнем регистре; используются закреплённые таблицы скаляров Unicode 17.0.0. |
| `toLowerCase()` | 0 | Строка в нижнем регистре; используются закреплённые таблицы скаляров Unicode 17.0.0. |
| `replace(old, new)` | 2 | Замена всех вхождений old на new; пустой old возвращает исходную строку. Оба аргумента могут быть строками или символами. |
| `repeat(count)` | 1 | Строка, повторённая count раз; count<0 или переполнение — INVALID_ARGUMENT. |
| `format(arg0, ...)` | 0 | Замена вхождений %0, %1, ... на строковые представления аргументов; индекс вне списка оставляется как есть. |

`str(object)` преобразует любой объект в его строковое представление тем же способом, которым печать получает текст: `str(42)` даёт `"42"`, `str(true)` — `"true"`, `str(null)` — `"null"`, а строка возвращается без изменения. Вызов `str()` без аргумента даёт `INVALID_ARGUMENT`. Функция `str` не имеет формы метода.

Абстрактные обработчики этих функций не выполняют регистрозависимые преобразования текста при анализе: для известных констант они могут вычислить `char`, `string` или `boolean`-константу, для неизвестной строки возвращают соответствующий домен, а определённо неподходящий тип — `BOTTOM`. У всех `effects=none`.

## Процесс и исполнение модулей

- `exit(code)` принимает целое 0–255; неверные аргументы или вызов при инициализации
  модуля вызывают обычные исключения. Допустимый exit завершает весь процесс без
  пользовательских `finally`, join и повтора на VM. Первый допустимый вызов фиксирует
  код; сброс stdout/stderr имеет общий бюджет в одну секунду. См. [exit](../../module-exit-api.md).
- `spawn(function, ...)` запускает поток ОС с обычным происхождением функции;
  `join(thread)` ожидает его результат или исключение. Запуск/ожидание потоков при
  инициализации модуля ограничены. Завершение главного потока не уничтожает модули,
  пока работают дочерние. См. [потоки](../../module-serialization-api.md).
- `__main__` и `__dir__` — контекстные константы, а не встроенные функции. Они сохраняют
  файл/модуль объявления, включая переэкспортированные функции. См. [модули](modules.md).
