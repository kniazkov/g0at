Редакция 2. Описываемая реализация: [commit 8d1fe86, с функцией `println`](https://github.com/kniazkov/g0at/tree/8d1fe867ff5272d8d59a44785871f0db1b454df0).

Словарь фиксирует употребление терминов в этой книге. Английские имена структур и флагов в исходниках сохраняются без перевода. Одинаковое слово «сводка» не делает сводку объявления и доказательство специализации одной структурой.

| Русский | English | Значение |
| --- | --- | --- |
| Лексема | Lexeme | Фрагмент исходного текста, распознанный как единица языка. |
| Токен | Token | Запись о лексеме, её виде и координатах. |
| Синтаксический анализ | Parsing | Построение структуры программы из токенов. |
| Свёртка правила | Reduction | Замена участка списка токенов одним узлом разбора. |
| Абстрактное синтаксическое дерево, AST | Abstract syntax tree, AST | Дерево конструкций программы без исходного оформления. |
| Область видимости | Scope | Лексическая область, определяющая связь имени с объявлением. |
| Связывание имени | Name binding | Установление ссылки использования имени на объявление. |
| Контекст | Context | Состояние исполнения области: данные, связи и управление. |
| Замыкание | Closure | Функция с сохранённым окружением доступа к внешним данным. |
| Захват | Capture | Зависимость функции от объявления за пределами её локальной области. |
| Арена | Arena | Область памяти для множества объектов, освобождаемых совместно. |
| Владение | Ownership | Ответственность за удержание и освобождение ресурса. |
| Счётчик ссылок | Reference count | Число удерживаемых ссылок, учитываемое объектом. |
| Сборка мусора | Garbage collection | Освобождение объектов, недостижимых из корней исполнения. |
| Байткод | Bytecode | Инструкции для программной виртуальной машины. |
| Код операции | Opcode | Числовой выбор обработчика инструкции. |
| Стек данных | Data stack | Последовательность значений с доступом прежде всего к вершине. |
| Абстрактное значение | Abstract value | Описание возможных конкретных значений. |
| Абстрактная интерпретация | Abstract interpretation | Вычисления над описаниями значений вместо конкретного запуска. |
| Решётка | Lattice | Частично упорядоченный домен с объединением и пересечением. |
| Объединение | Join | Приближение, покрывающее варианты обоих входов. |
| Пересечение | Meet | Описание значений, допустимых одновременно по обоим входам. |
| TOP / ⊤ | TOP / ⊤ | Любое значение; отсутствие уточняющих сведений. |
| BOTTOM / ⊥ | BOTTOM / ⊥ | Отсутствие возможного обычного значения; не объект null. |
| Передаточная функция | Transfer function | Правило изменения абстрактного состояния или результата узлом. |
| Сводка | Summary | Накопленные сведения об объявлении или функции. |
| Специализация | Specialization | Вариант анализа функции для упорядоченных типов параметров. |
| Граф вызовов | Call graph | Связи возможных вызовов между специализациями. |
| Сильно связная компонента, SCC | Strongly connected component, SCC | Группа вершин, каждая из которых достижима из каждой другой. |
| Неподвижная точка | Fixed point | Состояние, которое следующий шаг вычисления больше не меняет. |
| Побочный эффект | Side effect | Наблюдаемое действие помимо возвращаемого значения. |
| Чистота | Purity | Доказанное отсутствие учитываемых внешних эффектов; не гарантия завершения. |
| Недостижимость | Unreachability | Невозможность попасть в участок по рассматриваемым путям. |
| Бэкенд | Backend | Часть системы, формирующая целевой код. |

| ABI | Application binary interface | Договор о представлениях данных и вызовах между собранными частями. |
| Адаптер | Adapter | Обёртка между единым интерфейсом VM и типизированной C-функцией. |
| Возврат к VM | VM fallback | Переход к байткодному исполнению по разрешённым условиям. |
| Раздельная компиляция | Separate compilation | Сохранение подготовленной программы для последующего запуска. |
| Контрольная сумма | Checksum | Число для обнаружения изменения содержимого; не подпись автора. |
| Регрессия | Regression | Повторное появление ранее исправленной ошибки. |
| Медиана | Median | Средний по порядку элемент отсортированной выборки нечётного размера. |

Термины относятся к описываемой реализации. Например, «раздельная компиляция» здесь не означает систему импортируемых исходных модулей, а «чистота» не расширяет числовой ABI. Подробности — в главах 14–20 и 23–26.
