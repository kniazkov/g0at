# Значения ByteArray

`str(#00aAff)` и `#00aAff.toString()` возвращают `"#00AAFF"`. Пустой массив записывается как `#`. Преобразование создаёт снимок: последующая мутация его не меняет. Массивы и объектная нотация используют тот же uppercase hex, пригодный для разбора как литерал Goat. Метод `toString` не принимает аргументов.

`==` и `!=` сравнивают длину и байты. Другие типы не равны ByteArray в обеих позициях операндов, без преобразований. Явные переопределения операторов сохраняют обычный приоритет. Внутреннее сравнение ключей остаётся по идентичности: одинаковое содержимое не объединяет разные ключи. Операторы порядка для ByteArray не определены.

Пустой ByteArray ложен; любой непустой истинен, включая `#00`. Потомки с байтовым payload следуют тем же правилам. Перед выделением hex-строки проверяются умножение и место для префикса/терминатора; overflow следует существующей фатальной политике выделения памяти.

Тесты проверяют все 256 байтов через snapshot/parser roundtrip, вывод во вложенных массивах, разные типы, наследуемые операторы, мутации, truthiness, идентичность ключей и границы расчёта размера. Языковой сценарий выполняется из source и GBIN в режимах оптимизации/native.
