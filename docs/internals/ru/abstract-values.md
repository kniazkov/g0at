# Абстрактные значения, состояние и пределы анализа

[Contents](index.md) · [English](../en/abstract-values.md)

## Множество возможностей, а не пробное исполнение

Абстрактное значение описывает возможные значения времени исполнения. TOP допускает
любое значение; BOTTOM — ни одного. BOTTOM не является Goat null. Целая константа
точнее интервала, а интервал точнее INTEGER. Номера enum не задают этот порядок.
lattice_join() объединяет альтернативы, lattice_meet() пересекает ограничения.
Объединение констант 1 и 3 может включать 2: такая потеря точности безопасна, поскольку
результат по-прежнему покрывает оба пути.

Арифметика в `src/analysis` учитывает домены и крайние случаи runtime. Точный ответ
сохраняется только при доказанности; иначе возвращается тип или TOP. Нельзя просто
использовать знаковую C-арифметику для свёрток: переполнение, особые случаи деления,
NaN и знаковые нули требуют существующих семантических вспомогательных функций.

## Текущий факт и история

`abstract_state_t` сопоставляет идентичностям деклараций текущие значения и накопленные
сводки. Текущее значение описывает знание в данной точке. Сводка включает ранее
наблюдавшиеся значения и позднее записывается в декларацию. Подставлять её вместо
текущего значения при выборе ветки нельзя.

clone_abstract_state() изолирует изменяемые карты через копирование при записи.
Декларации, неизменяемые элементы решётки, арена и сборщик наблюдений заимствуются.
join_abstract_states() объединяет сводки обоих путей, но текущие факты берёт только
с нормально продолжающихся путей. Ветка с return даёт наблюдения, но не состояние
для следующей инструкции.

## Вызовы, циклы и конкурентность ограничивают знание

Неизвестный вызов сбрасывает факты, которые нельзя сохранить с учётом его эффектов.
Известные вызовы различают локальные переменные вызывающего и захваченное состояние.
Рекурсию и циклы нельзя бесконечно разворачивать. widen_loop_state() объединяет
обратное ребро и расширяет меняющиеся значения до доменов типов, пока текущие факты
не стабилизируются. Потеря константы здесь намеренна и не означает сбой исполнения.

Для возвращаемых типов функций есть отдельное ограниченное вычисление неподвижной
точки, описанное в [функциях](functions.md). Исчерпание лимита оставляет результат
неокончательным. При чувствительности к доступу или конкурентности analyze() выбирает
консервативный путь: общие изменяемые факты и наблюдаемые идентичности областей
запрещают обычное удаление; работает лишь ограниченный безопасный упрощатель выражений.
Новое доказательство обязано учитывать эти ограничения.

## Переписывание использует доказательства

simplify_graph() вызывается после достижимости и классификации свойств. Узлы замены
сохраняют оригиналы, чтобы restore_graph() подготовил повторный анализ. Известный
результат сам по себе не разрешает удалить вычисление: существенны эффекты, вызовы и
исключения. can_discard_expression() строже признака чистоты. Конкретные примеры
сохранения эффектов находятся в [ветвлениях](static-analysis.md).
