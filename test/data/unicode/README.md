# Portable scalar string fixture

`scalars.gbin.hex` is a full executable image independently generated by the
historical Python `struct`/UTF-32LE recipe, not with the C writer under test.
It contains empty, ASCII, Cyrillic, supplementary, combining and embedded-zero
strings. Its exact bytes are consumed unchanged by the real C loader on Linux
and Windows. The current image is `GOATPG01` v1 around the `GOATBC01` bytecode;
the old transitional signatures are rejection cases, not this fixture's format.

Build the project, then verify the fixture and Unicode behavior with:

```sh
ctest --test-dir build -R '^native[.]unicode$' --output-on-failure
```

The independent C constructor in `test/src/functional/unicode_cases.c` checks
these bytes before the production loader runs. Normal tests never regenerate
or repair the fixture. The former `scripts/check_unicode.py --generate` recipe
is historical source at
[`cbfdf31625a76313807c93ebc55258616e30454a`](https://github.com/kniazkov/g0at/tree/cbfdf31625a76313807c93ebc55258616e30454a),
not a current command. See the [scenario map](../../src/functional/README.md).
